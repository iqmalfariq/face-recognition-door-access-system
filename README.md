# 🔐 Face Recognition Door Access System

> A smart door access system that combines face recognition with mobile approval authentication for controlled and secure access.

## 📌 Project Overview

This project is a **Face Recognition Door Access System with Mobile Approval Authentication** developed as my Final Year Project.

The system combines a camera-based face recognition system with a mobile application to provide an additional authentication and approval mechanism for door access.

The project integrates hardware, software, computer vision, mobile application development, and cloud services into a single access control system.

---

## ⚙️ Key Features

- 👤 Face recognition for user identification
- 📷 Camera-based facial detection and recognition
- 🔐 Controlled door access
- 📱 Mobile approval authentication
- ☁️ Firebase integration
- 🖥️ Raspberry Pi-based system
- 🔄 Communication between the door access system and mobile application

---

## 🏗️ System Workflow

The general access process follows these stages:

**1. Face Capture**

The camera captures the face of the person requesting access.

**2. Face Recognition**

The system processes the captured face and checks whether the person is a registered user.

**3. User Verification**

The system verifies the identity of the detected user.

**4. Mobile Approval**

The access request can be sent to the mobile application for additional approval.

**5. Access Decision**

Based on the authentication and approval process, access is either granted or denied.

---

## 🧠 Computer Vision

The system uses computer vision techniques to process facial information captured through the camera.

Face recognition is used to identify registered users before allowing access to the system.

The Raspberry Pi acts as the main processing platform for the door access system.

---

## 📱 Mobile Application

A mobile application is integrated into the system to provide mobile approval authentication.

The application allows an authorized user to review and approve access requests remotely.

Firebase is used as part of the communication and data management between the system and the mobile application.
